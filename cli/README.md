# @yea-protocol/cli

The `yea` command for [YEA](https://github.com/yea-protocol/yea), the protocol for AI agents acting on your behalf: *Your Explicit Approval*.

```sh
npx @yea-protocol/cli demo       # a narrated session: services, a human's policy, consent and undo
npx @yea-protocol/cli install    # give your AI tools (Claude Code, Cursor, Codex, …) safe actions
npx @yea-protocol/cli --help
```

The library is [`@yea-protocol/sdk`](https://www.npmjs.com/package/@yea-protocol/sdk). Docs: https://yea-protocol.github.io/yea/
